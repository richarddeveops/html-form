HTML FORM ATTRIBUTES — NOTES

CHECK OUT ALL THE ATTRIBUTES YOU CAN USE ON HTML FORMS

1. type
   Tells the browser what kind of input this is.
   Examples: text, email, password, number, date, checkbox, radio, tel, url, file, hidden

2. name
   Gives each field a name so the value can be identified when the form is submitted.
   Example: <input type="email" name="contact">

3. id
   A unique ID for the element.
   It is used with the label's for attribute.
   Example: <label for="firstname">First name</label>
            <input type="text" id="firstname">

4. placeholder
   Shows hint text inside the input while it is empty.
   Example: placeholder="First name"

5. value
   Gives the input a default value.

6. required
   Makes the field must be filled before the form can be submitted.
   If the field is empty, the browser blocks submission.
   Example: <input type="text" required>

7. disabled
   The user cannot type in it and it is not sent with the form.

8. readonly
   The user can see it but cannot edit it. The value is still sent.

9. maxlength / minlength
   Limits how many characters can be used.

10. min / max / step
    Used for number, date, and range inputs.

11. pattern
    Lets you set a rule using a pattern.
    Example: only numbers, email format, etc.

12. autocomplete
    Controls whether the browser suggests saved values.
    Example: autocomplete="on" or autocomplete="off"

13. autofocus
    Moves the cursor to that field automatically when the page loads.

14. checked
    Pre-selects a checkbox or radio button.

15. multiple
    Allows more than one file or option to be chosen.

16. list
    Connects an input to a datalist of suggested values.

WHAT DOES REQUIRED DO IN HTML FORM?

The required attribute is built-in browser validation.
It tells the browser: "This field must be filled before the form can be submitted."

Example:
<input type="email" required>

If someone leaves it empty and clicks submit, the browser will stop the form and show a message like:
"Please fill out this field."

This is useful for important fields like:
- First name
- Surname
- Date of birth
- Gender
- Mobile number or email
- Password

In the uploaded form, required should be added to fields that must not be left empty.

USE LINE INSTEAD OF BOX IN INPUT

HTML controls the structure and behavior of the form, not the visual style.
The box around an input is the browser's default styling.

The underline/line look is a CSS job, not an HTML attribute job.

2. WHAT DOES "required" DO?
===================================================

"required" is built-in browser validation — no JavaScript needed.

Example:
    <input type="email" required>

If Submit is tapped while a required field is empty, the browser
blocks submission and shows a small popup: "Please fill out this field."

In your form, fields like First name, Surname, Date of birth, Gender,
Mobile number/email, and Password should all carry "required" — Facebook
doesn't let anyone sign up with any of those left blank.

Applied to your existing code:
    <input type="text" placeholder="First name" required>

Straight up: this specific change is a CSS job — the box/border look

Once CSS is introduced, this will just be a couple of style rules
